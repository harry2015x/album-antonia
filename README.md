# Antonia · Mis primeros tres años

Álbum familiar para presentar en pantalla (1920×1080): 65 páginas en 5 capítulos
(nacimiento, bautizo, primer, segundo y tercer año).

## Ver el álbum

Abre `index.html` en el navegador o en la dirección de Vercel.

- **Ver con música**: avanza solo cada 9 segundos, con música.
- **← →**: pasar páginas · **A**: automático · **M**: música · **F**: pantalla completa

La música es una melodía original tipo cajita musical que se genera en el navegador.
Para usar otra canción, pon un archivo `musica.mp3` en esta carpeta.

## Cambiar fotos o textos

Edita la lista `PAGINAS` en `generar.py` y ejecuta:

```
python generar.py
```

Las fotos se indican por su ID de `catalogo.json` (por ejemplo `N012`, `U027`).
